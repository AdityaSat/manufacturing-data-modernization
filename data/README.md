# Data provenance

- Dataset: AI4I 2020 Predictive Maintenance Dataset, UCI Machine Learning Repository, 2020.
- DOI: https://doi.org/10.24432/C5HS5C
- Source: https://archive.ics.uci.edu/static/public/601/ai4i+2020+predictive+maintenance+dataset.zip
- License: Creative Commons Attribution 4.0 International, https://creativecommons.org/licenses/by/4.0/
- Retrieved: September 21, 2026.
- `raw/ai4i2020.csv` is the unmodified original file.
- The pipeline adds engineered features, split labels, model scores, and SQL aggregations. Those are project-generated transformations.
- The exact source SHA-256 appears in `reports/model_metrics.json`.
- `warehouse.db` is generated locally and excluded from version control.

No financial costs, physical machine identities, or real-factory savings can be inferred from this file.
